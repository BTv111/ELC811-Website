# ELC811 Interactive Revision Platform

A simple, browser-based revision website for the **ELC 811 Electronics**
course. The project consists of a main landing page that links to two
standalone HTML applications: the question bank and the past-exams
section.

## Project files

  -----------------------------------------------------------------------
  File                                Purpose
  ----------------------------------- -----------------------------------
  `Index.html`                        Main homepage. Provides access to
                                      both learning applications.

  `ELC811_Question_Bank.html`         Interactive question-bank
                                      application for revision and
                                      practice.

  `ELC811_Past_Exams.html`            Past-examinations application.
  -----------------------------------------------------------------------

## How to use

1.  Select the **Question Bank** or **Past Exams** link from the
    homepage.
2.  Use the applications in the browser.

No installation or server is required for basic local use. If a feature
relies on browser capabilities or external resources, an internet
connection may be needed.
